# Cozy Client

A cozy, axolotl-themed client for **Minecraft 26.2**: underwater menus, a custom HUD, zoom, freelook, custom crosshair, chat heads, shaders support and a little axolotl friend.

## Download

Get it from the **[latest release](https://github.com/ItzAaronUwU/cozy-client-releases/releases/latest)**. The Cozy Launcher installs Minecraft 26.2 with Cozy Client and keeps itself and Cozy Client up to date automatically.

- **Windows:** download `CozyLauncher-Setup-x.y.z.exe` and run it.
- **Linux / Steam Deck:** download `CozyLauncher-x.y.z.AppImage`, make it executable (right-click → Properties → Allow executing as program, or `chmod +x CozyLauncher-*.AppImage`) and double-click it. No Proton or Wine needed. If it won't open on an older Ubuntu, install FUSE with `sudo apt install libfuse2`.

Windows may show "Windows protected your PC" because the files aren't code-signed: click **More info**, then **Run anyway**.

In game, **Right Shift** opens Cozy Settings.
